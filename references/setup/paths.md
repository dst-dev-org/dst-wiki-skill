# 外部知识路径

K／S／T 均为文档占位符，执行前替换为实际绝对路径。外部知识根与工具箱根不由当前目录、Skill 位置或邻仓推算，不扫描磁盘或自动 clone。缺少当前任务必需路径时集中确认一次；已有信息足够则继续。更新 Skill 不覆盖个人配置。

同会话已确认且未变化的 K／S／T 分别复用，不因流程切换或再次遇到链接而重读本文件、配置或重跑定位脚本。仅所需定位结果缺失、已知相关路径／配置变化或实际访问失败时重查相关项。

## K：知识根

知识资产目录，按顺序定位：

1. 优先使用用户本次明确的绝对路径。
2. 未指定时，读取用户主目录 `~/.dst-wiki/config.json` 的 `knowledge_root`。
3. 仍无法确认路径或可用状态时，按下表的“定位工具与异常处理”入口尝试一次脚本检查；已确认两处都没有 K 时，集中询问位置，或按下表引导取得知识资产，不空跑脚本。

确认 `K/wiki/index.md` 可读即可进入当前任务；已有有效定位不重复运行脚本或加载首次使用说明，缺根索引不自动新建。

源码为 `K/raw/current/scripts/`，其父目录 `BUILD.txt` 记录版本，生成物为 `K/output/`。

## S：当前 Skill 根

以宿主提供的当前加载 `SKILL.md` 的实际绝对路径所在目录为准，用于解析包内链接与调用随包脚本。S 绑定当前 Skill 包；切换 Skill 时使用该包的 S，不沿用另一包的安装根。

## T：可选工具箱根

仅工程增强需要时定位。本次明确的绝对路径优先，否则读同一用户配置的 `toolbox_root`；缺失或失效不阻断基础查询／维护，不为普通任务要求补齐 T。已确认缺失／不可用的结果也按上述条件复用，不重复尝试或提示安装。

确需工程增强且尚未取得工具箱时，向用户提供 [dst-toolbox 工具箱仓库](https://github.com/dst-dev-org/dst-toolbox) 获取地址，可下载 ZIP 或 clone；按用户请求取得并使用其指定的目标绝对路径，不自动安装工具或环境。

## 按条件追加读取

| 当前情况 | 读取 |
|---|---|
| 尚未取得知识资产，需要取得知识仓 | [取得知识资产](first-use.md#取得知识资产) |
| 首次选定有效 K／T，或要求保存／切换默认路径 | [保存配置](first-use.md#保存配置) |
| 用户明确要求新建空库 | [空库初始化](first-use.md#明确新建空库) |
| 前两级仍无法确认、需要一次脚本检查，或配置／目录／根索引异常 | [定位工具与异常处理](first-use.md#定位工具与异常处理) |
| 需补源码证据而快照缺失／损坏，或要求准备／更新源码、使用历史快照、处理版本检查失败 | [源码准备](prepare-source.md) |

仅查现有 Wiki 且证据足够时，不提示先准备源码；源码或安装不可用时报告核验边界，继续可执行部分。
