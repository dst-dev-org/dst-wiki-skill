# Skill 优化清单（B01–B02 返工复盘）

日期 2026-11-08。输入是两批的实际返工记录：B01（9 页／30 注册）外部复检两轮（P1×1／P2×12／P3×1，修订后余 5 项）；B02（3 页／28 注册）外部复检三轮（P1×2／P2×8／P3×1，修订后余 6 项，再复检余 3 项）。两批的写作阶段都是一次成型、结构校验一次通过，返工全部发生在「检视—修订—复检」这一段。

## 一、返工画像

| 阶段 | 实际发生 | 代价 |
|---|---|---|
| 写作 | 一次写成，validate_page 首跑即过 | 无 |
| 检视 | 只出报告与建议，改页由他人执行 | 每轮往返 10–35 分钟，改页方要重新回源码 |
| 修订 | 页面贴到 32 KiB 上限（B02 两页只剩 11 B／8 B） | 必须同句替换，压缩时先删“看起来最不关键”的限定语 |
| 复检 | 每轮只收敛一半（11 → 6 → 3） | 三轮才收口 |
| 副作用 | 自记字节／锚点数每改一次就失真 | 每轮都要回头同步数字，而改数字又改变字节数 |

主代理直改三批共 20 处，其中 **3 处是改页时新引入的**：把限幅写成负数再配 `max(delta, -上限)`（字面成升温）、把 `SANITY_SMALL` 写成 5（实为 10）、忘了同步自记字节数。这三处都不是“看漏了源码”，而是**写作与改写的动作本身没有检查点**。

## 二、根因

1. **复审只“报告”不“改”**：建议与落笔之间隔着一次转述，限定语最易在转述里丢。
2. **尺寸贴顶**：页在 99% 上限时，任何补充都得先删等量内容，删掉的多是限定语，于是准确度下降。
3. **数值只写结果不写出处**：缺“常量名＝值＋锚点”的三件套，改页时无法就地复核。
4. **正负号与方向无检查点**：限幅、`max`/`min`、负收益、负理智，写反了结构校验也发现不了。
5. **跨页措辞漂移**：同一机制在三页各写一套（“夹到”对“上限”、“原样返回”对“钳零”），复检只能逐页挑。
6. **自记数字与内容耦合**：正文写死行数／字节／锚点数，等于给自己埋一个每改必坏的字段。

## 三、优化清单

### P0 必改（不改就继续返工）

| # | 改哪里 | 加什么 | 本轮证据 |
|---|---|---|---|
| 1 | `assets/prompts/source-review.md` | 增加 `review+fix` 模式：报告后**直接改认领页**，规定“逐句替换、不叠加解释”，报告加「已直接修改（行号→改前→改后→依据）」节 | B02 三轮里两轮是“报告→他人改→再报” |
| 2 | `references/maintain/write-format.md`「文件大小」 | 同批并行页按 **85% 上限**收束，留 1–2 KiB 修订余量；确需贴顶时在验证记录写明“已无修订余量” | B02 A/B 分别剩 11 B／8 B，压缩中丢限定语 |
| 3 | `assets/templates/prefab.md` 与复审重点 | 任何数值断言写「常量名＝值」并给锚点；**改页后回读常量**再落笔 | `SANITY_SMALL` 被写成 5，实为 10（5 是 `SANITY_TINY`） |
| 4 | 同上 | 涉及“上下限／速率／`max`／`min`／负值”的句子一律写**正幅度＋公式**，禁止“负上限 + `-上限`”双负 | 把限幅写成 −1／−5 又配 `max(delta, -上限)`，字面成升温 |
| 5 | `references/maintain/write-format.md`「元数据／验证记录」 | 页面只记**档位与上限**（如“standard 档，240 行／32 KiB 内”），**禁止手写**行数／字节／锚点数；需要数字时由 `validate_page` 输出 | B02 同一轮内三次回改字节数 |

## 四、交付前自检卡（建议直接抄进 `new-pages.md` 收口与复审模板）

- [ ] 每个数值：常量名＝值＋锚点，且**改页后回读过源码**
- [ ] 每个“上限／速率”：正值＋公式，无双负
- [ ] 每个“读档／构造”结论：写明 `OnLoad` 覆盖与比例封顶
- [ ] 每个名称：给 `chinese_s.po` 行号，未用 `strings.pot`
- [ ] 每页：≤85% 上限；正文未手写行数／字节／锚点数
- [ ] 跨页：同一机制措辞一致（关键词 grep）
- [ ] 锚点：起点非空非结构行，终点非空
- [ ] 索引与回链已登记；日志体积在限内

## 五、不建议改的

- **不把“每页必须 N 轮复审”写进规则**：问题在转述与尺寸，不在轮数。
- **不提高 standard 档上限**：B02 的毛病是把“解释”写成“叠加”，不是内容必须更多。
- **不为单页开特殊档位**：先按去重与拆分解决，档位是最后手段。

## 六、预期效果

按 P0 五条执行，B02 那种“11→6→3”的收敛曲线应压到一轮：复审方直接落笔（1）、页面留得住余量（2）、数值与方向就地可核（3、4）、自记数字不再是回头改的负担（5）。P1 五条主要防“同一坑连踩两批”和“三页各说一套”。
