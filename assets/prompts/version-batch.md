# 版本维护任务派发模板

仅实际派发或交接版本维护任务时读取，复用批量协议已确认的范围与规则；普通查询和独立逐页修补不加载。每组使用同一骨架，只替换实际输入与页清单。

## 派发前确认

1. **可派发页面：** 切片只是候选快照。主代理将其与当前维护候选、已验收及处理中页面对账；有先行改动但尚未验收或仍需基线收尾的页，先留给主代理核对，不重复派发。候选包含版本落后、review-needed、未登记及必要关联页，不能只取哈希漂移队列；输入有变化时仅刷新相关范围，不为每次派发重跑全库检查。不同工作组的写入页互斥。
2. **实际源码输入：** 将 K／S／所需 T、可用的旧新 scripts 根替换为实际绝对路径，核对 BUILD 与快照身份、本批实际需要读取的文件；只有目录或 BUILD.txt 不算可对比基线。旧输入不同的页面分组或逐页注明映射；已知新增／删除注明仅存在的一侧，不把未知缺失当正常变化。缺输入先修正路径或注明受限范围，不能要求代理猜路径；已核验报告足以覆盖的用法可明确派为报告复用，不为此补齐旧快照。
3. **可用判断依据：** 写明适用报告条目、已审阅 diff／迁移预览的实际入口及覆盖范围；没有则填“无”。已完成、处理中和待收口依据来自实际页面改动与验收结果，record 数量或队列出队不能单独证明任务完成。

## 可直接填写的任务文本

派发前填完必要输入，删除不适用的可选项；不能把未替换的占位符交给执行者。

```text
任务：修补本批 DST Wiki 页，完成后交主代理验收。
K（知识根）：<绝对路径>
S（知识 Skill 根）：<绝对路径>
T（可选工具箱）：<绝对路径；不可用则注明>
旧 scripts 根／版本：<实际绝对路径及编号体系:版本；不可用则注明>
新 scripts 根／版本：<实际绝对路径及编号体系:版本>
本批页清单（相对 K/wiki）：<逐页列出，不只给切片名称>
名单核对：<候选依据、所检范围及时点；已排除的已验收／处理中页>
输入核对：<旧新结构及本批所需文件的检查结果；预期新增／删除例外>
已有判断依据：<报告条目／已审 diff／可选迁移预览及覆盖范围，或“无”>

执行 S/references/maintain/maintain-version.md，以及批量协议的命中分支；
已有证据充分则复用，不为字段格式或行号变化重读整份源码。
只改本批知识页；共享索引、报告、日志与 source-baseline.json 由主代理统一收口，
需新增 sources 可写入本页，需增补共享报告的结论随结果返回。

需要旧新对比而输入缺失时，返回缺失路径与受影响页面；
不得静默改为当前实现审阅并声称完成旧新对比。
已核验报告可支持其实际覆盖部分，未覆盖部分保留阻塞。
如派发后发现页面被其他任务修改，先交主代理核对，不覆盖对方改动。

返回：页名｜处理类型｜锚点实际修改／检查数｜新增 sources｜检查结果／未检项｜阻塞。
处理类型说明实际属于语义修订、仅锚点、无需改动或阻塞，不新增 frontmatter 状态。
有迁移提议的页附实际落地的差异或对应位置；无需改动的引用说明沿用依据。
不把预计修改数、计划检查或页内完成声称当成实际结果。
回报表示已修补待验收，不声称主代理尚未执行的 record 或整批验收已完成。
```

## 交接给主代理

主代理对齐派发页与返回页，区分可验收页、阻塞页及无需 record 的页，再按批量协议收尾。实际改动、引用与结论的适用依据共同支撑完成判断；页内文字、哈希基线或队列单独一项都不够。不为统一返回表而创造新状态文件或知识页字段。
